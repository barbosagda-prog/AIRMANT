# AIRMANT

Sistema de gestión de mantenimiento aeronáutico MRO.

## Tecnologías

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Objetivo

Gestionar información relacionada con aeronaves,
mantenimiento, órdenes de trabajo, inventario,
personal técnico, usuarios, roles y documentación.
